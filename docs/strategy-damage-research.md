## 二、公式分別適用的通道

### A：個人筆記中的角色傷害假說

`角色傷害 ≈ 基礎攻擊 × (1 + P × 0.2 + D) × T × (1 + F)`

P 為潛能數量，D 為攻擊／技能增傷，T 為天賦補正，F 為最終增傷。作者稱其為推測公式，因此「每個潛能 +20%」不是已驗證的通用常數，也未自動加進工具。

作者建議拿不準時選擇數字高的策略，**並未證明**不同事件傷害可直接相加、每秒傷害能和單次傷害互換，或這個排序一定能代表實戰強度。

### B：中文社群的乘區整理

策略通道：

`策略基礎傷害 × (1 + 策略自身增傷) × (1 + 策略傷害增傷) × (1 + 最終／受到／角色所有傷害增傷合計) × (1 + 五號化合物增傷) × 個別特殊乘區`

角色通道：

`角色基礎攻擊 × 招式動作倍率 × (1 + 潛能及其他同桶加算) × 各獨立乘區 × 最終結算乘區`

同桶先相加，再將不同桶相乘。暴躁觸手的最後一擊等特殊項不能套成全部策略的全局增幅。

兩篇文章的對象與粒度不同。目前不能斷言兩套公式已相互驗證或一定等價；角色通道也不能直接拿來證明策略通道的全部倍率。

## 三、目前工具已做到的部分

| 層次 | 現況 |
|---|---|
| 固定數值 | `CompassDamage` 分開命中與持續來源；半秒跳傷換算為每秒；固定加傷與百分比加傷分開 |
| 自身增傷 | 以策略樹與必要的指定目標限定作用對象；`group` 是作用範圍，不能僅因同用 group 就判定混成全局乘區 |
| 全局乘區 | DPS 情境有策略增傷、最終／受到／角色所有傷害合計、五號化合物三個獨立輸入；自身增傷不重填 |
| 時間與命中 | 每來源可設判定頻率、有效命中數與持續覆蓋率；未知頻率預設每秒一次，是假設而非實測 |
| 已知時間限制 | 地雷冷卻、高效布雷與普通光波充能會限制頻率；相關充能與站位條件視為成立 |
| 普通光波 | 可輸入未套用試算全局乘區的普攻基準，再依光波品質與自身增幅換算；不等於已加入角色本體 DPS |
| 紅策取得 | 只計已取得紅策與確認啟用傳承；計畫中的推薦目標不提前計入 |
| 缺失品質 | 不按比例外推，明確列為未計入 |

`reference = Σ各來源一次命中 + Σ各持續來源一秒` 是**無單位比較指數**。把各種 DoT 統一成每秒，只能統一 DoT 之間的時間單位；仍不能讓單次傷害變成同一物理單位。因此 reference 既不是 DPS，也不能稱為實際「一輪爆發量」。

## 四、本次補入的數量／機率

這一層只影響情境 DPS，沒有把「單次命中參考」偷換成整輪發射，也不更改固定傷害推薦的比較單位。

- 額外地雷：依品質機率 p，預設期望數量為 `1 + p`。地雷濺射以每顆六片計，並承接放置地雷的觸發頻率與數量。
- 多重冰刺：基礎一根加上品質對應的額外根數；最高品質為六根。
- 光槍：基礎兩支，多重光槍再增加兩支；聖光光槍也按對應光槍數量、來源頻率試算。
- 電球：基礎三顆，密集電球額外一顆。
- 飛劍：基礎兩把，多重飛劍改為總共三把，不是再增加三把。
- 多重影子：以一次原始判定為情境，額外兩個影子的期望數量為 `1 + 2p`；沒有無限展開再觸發。
- 冰雹頻率：每次原始冰雹判定的期望數量為 `1 + p`。
- 落雷飛刃、分裂毒彈、光陣電樁：依描述分別帶入三把、兩顆、兩座。

自動數量假設全部命中，不代表對同一敵人的實測命中率。自訂「有效命中數」會**取代**自動數量，不會再相乘；可以恢復自動，品質與策略改變後會重新計算預設值。

火彈會同敵衰減，雖知道發射十顆／強化後十四顆，仍不直接當十／十四次完整傷害，預設等效一次並註明限制。影子反沖、影子冰刺、冰刺再生、影子電球等未完整核實的複製／連鎖，會顯示缺口，而不是將 utility 一律當作零輸出或任意倍乘。

## 五、自訂內建 CD 與解除假設

每個命中來源新增「自訂內建 CD（秒）」：空白表示未知；0 表示試算者明確假設沒有此限制。填入正數時，頻率上限為其倒數，並與已有的冷卻／充能上限取較低者。

技能槽與衝刺槽各有預設關閉的「解除自訂內建 CD」假設開關。它們只忽略相應承載槽位的自訂 ICD；**不取消地雷放置冷卻、光波充能或父來源的觸發限制**。未把讀取失敗的契約頁當作證明，也未猜測未知 ICD 數字或硬套契約名稱。

已確認一對一衍生的第二段火環、地雷濺射與聖光光槍會承接父來源頻率，不會在父來源停止觸發時仍各自產生每秒一次傷害。其他紅策連鎖尚未自動建立完整動態時間軸。

| Naoto 蓄力、個別招式倍率與動作高手 | 原紀錄報值為 Naoto 通常／滿蓄約 1.2／1.5 倍、Enhancer 合計約 1.2 倍／Full Drive 約 1.5 倍、動作高手每個金色策略 +22%；尚未逐頁／逐版本交叉核對，未自動輸入模型 |
| 暴躁觸手特殊乘區、處決與最大生命比例 | 需區分最後一擊、精英／Boss 與生命條件，不能當普通全局倍率 |

290 選項的明示情境是：以每擊 290 **取代**召喚史萊姆的原每擊傷害與其自身加成，再套使用者的全局乘區；不將 290 額外加在舊傷害上。此情境方便比較，不代表已證明紅策與所有史萊姆升級的交互作用。

## 七、仍值得繼續驗證的項目

1. 逐槽、逐來源實測 ICD，記錄遊戲版本、品質、每次命中數與測試時間。
2. 核對解除契約的原始描述，分開事件冷卻、策略內建 CD 與充能。
3. 驗證紅策派生版本是否繼承普通節點倍率、數量與傳承品質。
4. 補全未知品質與角色招式動作值；完整角色 DPS 需要另一條傷害通道。
5. 建立有限的觸發鏈與同狀態疊加規則，避免無限遞推或重複計數。
