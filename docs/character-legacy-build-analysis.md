# 全角色技能與雙傳承構築分析

研究日期：2026-10-19。範圍：本專案 17 名角色，優先按 Steam／PC《蒼翼：混沌效應》資料討論；其他平台與《混沌效應 X》不能直接套用全部細節。

本報告依據 `character-data.js` 的潛能／隱藏效果、`strategy-data.js`、`tactics-descriptions.js`，交叉核對 BlazBlue Wiki 與官方更新。下列推薦是機制導向的候選，不是已實測的全角色最強排名。沒有實機逐幀、MP／SP 收支與當前版本冷卻測量，因此不將高覆蓋率寫成永久無敵。

## 1. 結論與傳承規則

值得優先試的方向：

| 方向 | 先試主角 | 兩個傳承來源與指定技能 | 判斷 |
|---|---|---|---|
| 遠程傷害 | 雷琪兒、九重、Λ-11 | 諾愛兒「快速裝填 EX」＋拉格納「血之興奮 EX」 | 增傷、回 MP 與持續攻擊相配，傷害流成立；倍率不能直接全乘 |
| 普攻／連擊傷害 | 直人、響音 | 麻衣「楓華」＋桃兒卡卡「咔滋咔滋」 | 技能後普攻增傷＋連擊增傷，適合能維持連擊的打法 |
| 減傷吸血 | 拉格納 | 白面「金剛」＋直人「血之尖刺」 | 能堆容錯，但減傷有條件、有空窗，不能據此宣稱 100% 減傷 |
| 反覆格擋無敵 | 白面、雷琪兒、直人 | 梟首者「繭」＋九重「平面迷霧」 | 「繭」成功格擋重置 CD 是明確循環機制；無縫銜接仍待測 |
| 閃避觸發 | 桃兒卡卡、Es、艾希、哈札馬 | 琴恩「冷凍」＋九重「平面迷霧」 | 易組成閃避、控場、輸出循環；九重當主角時改第二來源 |
| 閃避附加傷害 | 桃兒卡卡、艾希 | 琴恩「冷凍」＋Es「紋章術」 | 兩個閃避天賦一起使用，攻防兼具；依賴真正閃過攻擊 |
| 高覆蓋控場 | 高連擊主角 | 哈札馬「銜尾蛇」＋琴恩「冷凍」 | 命中縮短傳承 CD，配黑洞減速與傳承減 CD 有機會提高覆蓋 |
| 閃避回 MP 循環 | 白金 | 暫以琴恩「冷凍」＋諾愛兒「快速裝填 EX」 | 官方確認閃避回 MP 與腳底抹油互動，缺數值，列研究候選 |

開局選的是兩名其他角色的資料體，各自帶入天賦、一個指定傳承技與保存的策略；不是將那個角色整套潛能搬過來。同一來源的兩種傳承技是選項，不能把「白面迅雷＋白面金剛」當作兩名不同來源。第二傳承技需要先完成對應解鎖；未解鎖時不能將本報告的 EX／第二技當作開局現成選項。[傳承規則](https://blazblue.wiki/wiki/BlazBlue_Entropy_Effect/Prototypes)

主角本人的天賦已經在身上，表中不重複選自己。兩個資料體攜入的紅策也需要符合實際啟用條件，不能由「開局帶入」推導成所有效果無條件啟用。

## 4. 極端流派如何成立、在哪裡會斷

### 傷害流：成立，但要先分傷害來源

遠程本體輸出先試「諾愛兒裝填＋拉格納 EX」；能穩定無傷連殺的技能角色，也可試「九重＋拉格納」。以普攻為主、能高頻穿插技能者先試「麻衣＋桃兒卡卡」。以策略傷害為主則優先研究拉格納 EX、芭烈特後燃器這類全傷效果，不能假設每個「技能傷害 +X%」都提高策略傷害。

九重的零件＋射線、雷琪兒的插桿＋落雷是本體多來源／多命中放大；效果還取決於 Boss 體積、桿／零件數量與命中。不能單看角色基礎攻擊或各策略面板傷害加總決定強弱。[九重機制](https://blazblue.wiki/wiki/BlazBlue_Entropy_Effect/Prototypes/BBEE_Kokonoe)

傳承主動技本身的固定傷害、天賦增益、傳承觸發的策略傷害須分開記錄。增益同桶可能相加、不同桶才可能相乘；沒有來源分類與測量前，不宣稱兩個 +30% 必定變成 1.3×1.3。

### 減傷流：能做，但沒有證據支持常駐 100%

具體候選：拉格納＋白面金剛＋直人血之尖刺。拉格納的低血／回復玩法有機會吃到直人「敵方 HP 百分比更高時減傷」，金剛提供有時限的減傷與霸體，再找防禦型意識增幅。

注意直人條件會在自己回血、Boss 掉血時改變：進入收尾階段可能從減傷切換為增傷。金剛也有結束與冷卻空窗，不能把這組看成永久坦克。

若暫以獨立乘算假設，55% 與 25% 減傷會留下 `0.45×0.75=0.3375` 傷害，即減傷 66.25%；這只是說明「不能直接相加」的示例，不是遊戲疊加公式的實測結論。同類減傷、上限、結算順序仍要測。[金剛](https://blazblue.wiki/wiki/BlazBlue_Entropy_Effect/Prototypes/BBEE_Hakumen)、[直人條件](https://blazblue.wiki/wiki/BlazBlue_Entropy_Effect/Prototypes/BBEE_Naoto_Kurogane)

### 無敵流：繭最值得先測，雷琪兒新版很有潛力

第一候選是任一能穩定輸出的主角＋梟首者「繭」＋九重「平面迷霧」。繭成功格擋後給無敵、重置自身 CD；無敵期間攻擊，結束時用本體防禦技／傳送接續，再找下一次可格擋攻擊。

這是條件式可重複循環。無敵期間是否還能成功格擋並刷新、無敵到下一次架式的銜接是否留縫、敵人不出招時怎麼辦，都不能只靠文字保證。尤其不要把「繭普通無敵」直接當成「成功閃避」，預設觸發琴恩與 Es 天賦。[繭描述](https://blazblue.wiki/wiki/BlazBlue_Entropy_Effect/Prototypes/BBEE_The_Prisoner)

雷琪兒則可用本體跳／滑翔無敵閃避、月讀、全方位格擋接續。舊資料的月讀是 15 秒／45 秒 CD，單獨顯然留有空窗；官方 9 月更新又新增格擋得短時間月讀並降低詠唱 CD、詠唱起手／成功時無敵、月讀下詠唱不使其消失。這讓「本體防禦循環＋繭補縫」更值得測，但新增效果的完整潛能組合與持續時間仍待實機確認。[官方更新](https://steamcommunity.com/app/2273430/allnews/?l=schinese)

### 無限閃避流：高覆蓋成立，永久重置不能混為一談

優先角色為桃兒卡卡、Es、艾希、雷琪兒、哈札馬、直人，各有空中攻擊、防禦位移或無敵閃避強化。艾希五段衝刺代表一輪可用次數較多，並不自動代表第六次無縫補回。空中普攻次數重置也不等於衝刺回充。

最容易試的組合是桃兒卡卡＋琴恩冷凍＋Es 紋章術；若缺閃避入口，將 Es 換九重迷霧。利用本體閃避窗口觸發琴恩／Es，空檔以空中無敵普攻或其他本體招式補上。

需要分清三種效果：普通閃避能觸發閃避天賦，但部分紫色警示／抓取能穿透；普通無敵能防禦更多攻擊，卻不自動算成功閃避；無敵閃避兼有兩者優勢。個別招式描述有翻譯混用，須逐招確認。[防禦機制](https://blazblue.wiki/wiki/BlazBlue_Entropy_Effect/System_Mechanics)

琴恩頁面記載時之靜止期間無敵，但沒有在本次讀到的描述中提供完整再次觸發條件與內建 CD。不能由「3.5 秒」直接證明永續；普通無敵期也可能改變下一次閃避的觸發時機。

### 閃避策略機關槍：有機會，但策略 CD 與人物衝刺 CD 分開

「腳底抹油／Cut and Run」的描述是取消衝刺相關策略與天賦的觸發冷卻；不是無條件重置人物衝刺次數、全部技能或所有傳承。可研究衝刺飛劍／冰錐／落雷等，仍須量測每個策略的實際觸發間隔與命中。[意識／契約描述](https://blazblue.wiki/wiki/BlazBlue_Entropy_Effect/Mind_Unleashed)

白金特別值得研究：官方已修復腳底抹油對她天賦閃避回 MP 的 CD 減少不生效問題。若閃避頻率、回 MP 與本體消耗能平衡，有機會做出「閃避回 MP→技能輸出→再次閃避」。但目前不知道每次回多少、有效觸發頻率與完整潛能條件，先列候選。白金魔法幻影完全無視特定致命攻擊的舊異常已被官方修復，不能用舊影片當永久無敵證據。

### 控場流與資源循環：可另立成一派

哈札馬銜尾蛇命中減自身 CD，可以提高傳承策略施放頻率；配「黑洞減速」是值得試的方向，琴恩冷凍用來控場／銜接。高連擊角色若再拿到 Momentum Shift（每增加 30 連擊減傳承 CD 0.5 秒），有機會進一步提高覆蓋，但不是按一次永久黑洞。[哈札馬資料](https://blazblue.wiki/wiki/BlazBlue_Entropy_Effect/Prototypes/BBEE_Hazama)

如果基礎 CD 是 C、持續 d 秒、命中削減 r 秒，期間新增 H 連擊，理想化連續覆蓋需要接近 `C-r-0.5×floor(H/30) ≤ d`，且必須算施法動作、觸發結算時點及可否重疊。這是測量框架，不代入未確認的數字。黑洞減速還會縮短黑洞持續時間，不能只看減 CD。[策略描述](https://blazblue.wiki/wiki/BlazBlue_Entropy_Effect/Tactics)

MP 循環則要求平均回復不少於平均消耗。諾愛兒裝填 EX 是週期補給，不是無限 MP；哈札馬本體的強化蛇環比傳承版吸 MP 更完整，也不能互相替代。艾希依賴命中回 MP，若只閃避不攻擊會斷資源。

控場也可能降低以敵人位移觸發的撕裂傷害、減少可用來格擋的敵人攻擊；「所有防禦效果一起帶」不一定讓循環更順。

## 5. 實測順序與判定方式

1. 桃兒卡卡＋琴恩冷凍＋Es 紋章術：先取得三段衝刺與空中普攻無次數限制／無敵的對應組合。記錄能維持多久、落地／取消時有沒有受擊縫。
2. 雷琪兒＋繭＋平面迷霧：先補新版格擋與月讀前置，分別測月讀、繭、普通閃避的覆蓋，不能混記成同一種狀態。
3. 九重＋諾愛兒裝填＋拉格納 EX：固定同一 Boss、品質與策略，分開測 EX 前後本體技能與策略傷害，並記錄耗血／回復。
4. 拉格納＋金剛＋直人尖刺：固定敵方同一招，分別測單減傷／同時減傷，並控制雙方 HP 百分比；再測金剛結束後的生存。
5. 高連擊主角＋銜尾蛇＋冷凍：測空放／命中 CD、減 CD 意識前後及黑洞完整存在時間，再判斷能否接續。
6. 白金：補天賦完整數值與兩個傳承技，再測腳底抹油前後的有效 MP 回復頻率。

每次至少記錄平台版本、主角、兩名來源／技能與等級、關鍵潛能、意識／契約及負面條件。用同一敵人持續壓力情境測試，同時測一般攻擊、紫色警示與抓取；「一場沒受傷」只證明該場操作成功，不證明逐幀無縫。若要證明無限，還須確認循環結束後資源與冷卻回到可重複的狀態。
