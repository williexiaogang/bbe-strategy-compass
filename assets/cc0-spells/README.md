# CC0 spell-art pilot

Source: [Magic spell icons](https://opengameart.org/content/magic-spell-icons)

Author: **steefie92**. The asset page explicitly lists **CC0**.
License: https://creativecommons.org/publicdomain/zero/1.0/
Retrieved: 2026-10-18.

Original files are preserved as `spellicons-original.svg` and `magicicons-original.png`.

Local SVG adaptations:

- `burn.svg`: original flame artwork, isolated with a transparent background.
- `fire-projectile.svg`: the same original flame artwork rotated to suggest travel.
- `thunderbolt.svg`: original lightning artwork recolored violet to match the compass's electric element.
- `light-spear.svg`: two central facets from the original crystal artwork, recolored gold as a light-spear illustration.

Each adaptation retains its required source gradient definitions and uses a fitted viewBox.
These are third-party interface illustrations, **not official BlazBlue skill artwork**.
The pilot is restricted to 燃燒爆彈 / 爆燃火彈 and 落雷光槍 / 光槍落雷 progress badges.
No runtime network request or additional library is required. If an image fails, the existing element symbol is retained.
